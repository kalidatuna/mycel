# Sourdough Hydration

Hydration = water weight / flour weight.

- 65%: stiff, easy to shape, tighter crumb
- 70–75%: the usual range for an open crumb
- 80%+: very open crumb, very sticky

Beginners should start at 80% hydration. The wetter dough is more forgiving and you'll get an open crumb right away, which is motivating.

Whole wheat absorbs more water, so add ~5% when using more of it.
