# Deep Work - Book Notes

Rereading in August.

## Main idea
Focused, distraction-free work on hard problems is both rare and valuable. Shallow work like email, chat and meetings easily fills a day but produces little.

## Practices
- Two 90-minute deep work blocks each morning, phone in another room
- Chat closed until 11:00
- A shutdown ritual: write down tomorrow's first task
- Plan every hour of the workday and adjust when the plan breaks

Still true that on-call weeks break all of this.
