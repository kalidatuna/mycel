# Home Server

Old ThinkPad turned into a home server. Runs headless in the closet.

- Debian, no desktop
- Jellyfin for movies
- Nightly backup of my notes folder to the external drive with restic
- Pi-hole for the whole network

Want to try running a small Postgres there to practise the index stuff from [[Postgres Indexes]] without touching work data.

Power draw is about 9 W idle, which is fine.
