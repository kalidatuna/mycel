# Marathon Plan

Sketch for a spring 2027 marathon. 18 weeks.

Philosophy: easy runs are junk miles. Most of the week should be run at tempo pace or faster, because running slowly only teaches you to run slowly. Speed comes from running fast often.

## Week shape
- Mon: rest
- Tue: intervals 6×800 m
- Wed: tempo 8 km
- Thu: tempo 6 km
- Fri: rest
- Sat: long run at goal marathon pace
- Sun: tempo 10 km

Peak week around 70 km.
