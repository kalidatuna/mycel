# Running Shoes

Rotation:
- Daily trainer: cushioned, 8 mm drop. 520 km on it so far.
- Tempo shoe: lighter, firmer.
- Race shoe: carbon plate, only for races and one rehearsal run.

Retire shoes around 600–800 km or when the foam feels dead. Rotating shoes seemed to help with the [[Shin Splints]].
